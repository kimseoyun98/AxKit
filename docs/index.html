axpublish

디자이너의 Figma 파일을 AI가 읽고, 디자인 토큰을 바인딩하고, 반응형 웹 코드로 퍼블리싱하는 오픈 파이프라인입니다.

💡
한 줄 요약 Figma 링크를 주면 AI가 Figma에 토큰을 직접 바인딩하고, 반응형 HTML/CSS 코드까지 만들어 로컬에 내려줍니다.

왜 만들었나

웹 디자인을 AI가 퍼블리싱하려면, AI가 디자인을 읽을 수 있는 구조가 먼저 필요합니다. Figma의 하드코딩 파일은 AI가 패턴을 인식하기 어렵습니다.

axpublish는 Seed Design 토큰 시스템을 기반으로 Figma 파일을 정규화하고, AI가 일관된 규칙으로 코드를 생성할 수 있도록 만든 파이프라인입니다.

기존 방식axpublish
하드코딩 Figma (#1A2B3C 직접 입력)Semantic Variable로 바인딩된 Figma
AI가 색상을 제각각 해석시맨틱 토큰으로 일관 처리
반응형 규칙 없음, 매번 수동 정의clamp() fluid 타이포그래피 — 뷰포트에 따라 자동 스케일
Primary 컬러 바꾸면 전체 수동 수정hex 하나만 바꾸면 Figma + 코드 전체 반영
버튼을 화면마다 다시 만듦컴포넌트 라이브러리를 한 번 만들고 재사용

퍼블리싱 팀 & 사용자 여정

axpublish는 역할이 나뉜 5명의 AI 직원과 디자이너(당신)가 협업합니다. 각 직원 카드와 사용자 여정을 가로 슬라이드로 확인해보세요.

🔍 SCOUT → 🎨 BINDER → 📐 FLEX → ⏸ 디자이너 검수 → 🔧 BUILDER → 🏗️ ASSEMBLER → ⏸ 최종 검수
🔍
SCOUT
디자인 분석가
Figma MCP Read

디자이너의 Figma 파일 전체를 스캔하여 화면 목록, 컴포넌트, 색상/폰트 사용 현황, Variables 적용 여부를 분석해 팀에 브리핑합니다.

🎨
BINDER
토큰 연결 담당
Figma MCP Write

Figma 내부에 axpublish / Seed Variable Collection(59개 토큰, Light/Dark)을 생성하고 하드코딩된 색상을 시맨틱 토큰으로 1:1 자동 바인딩합니다.

📐
FLEX
반응형 초안 생성
responsive-rules.md

Desktop 프레임을 읽어 responsive-rules.md 기반으로 Figma 내에 Tablet + Mobile 초안 프레임을 자동 생성합니다. 디자이너 검수가 필요합니다.

🔧
BUILDER
컴포넌트 코드 제작
React + Tailwind v4

확정된 3-뷰포인트 디자인을 읽어 재사용 가능한 컴포넌트 단위로 코드를 생성합니다. Seed CSS 토큰만 사용하며 임의 하드코딩을 절대 자제합니다.

🏗️
ASSEMBLER
페이지 조립 담당
Page Assembly

BUILDER가 생성한 컴포넌트를 레이아웃에 맞춰 순차 조립합니다. 화면별 로컬 프리뷰 및 디자이너 검수를 거쳐 다음 화면 조립으로 진행합니다.

1저장소 클론
git clone https://github.com/kimseoyun98/axpublish-init.git
2필요한 파일 복사

클론한 폴더의 templates/ 안 파일들을 프로젝트에 복사합니다.

axpublish-init/templates/ ├── seed-seed-tokens.css ← 디자인 토큰 전체 ├── axpublish-orchestrator.md ← AI 팀 운영 지침서 ├── responsive-rules.md ← 반응형 규칙 ├── figma-seed-variables.json ← Figma Variable 템플릿 └── generate-seed-brand.js ← 브랜드 컬러 생성 스크립트
4브랜드 컬러 적용
node generate-seed-brand.js --primary "#0066FF" --output ./seed-seed-seed-tokens.css
5AI에 파일 첨부 후 시작

Claude / ChatGPT / Gemini에 axpublish-orchestrator.md 파일을 첨부하고, Figma 파일 URL과 함께 "SCOUT 시작해줘"라고 입력하면 파이프라인이 시작됩니다.
