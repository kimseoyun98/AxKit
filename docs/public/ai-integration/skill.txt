# AX Design System AI Integration Skill

AX Design System 통합 AI 스킬 명세서입니다. AI 에이전트가 AX Design System을 탐색하고 정확한 컴포넌트 스펙과 토큰을 사용하여 코드를 작성할 수 있도록 안내합니다.

## 1. 탐색 및 라우팅 (Routing)
- 컴포넌트 목록 및 디자인 명세 index: `/llms.txt`
- UI 스니펫 코드 위치: `docs/src/components/ui/`
- 전체 쇼케이스 갤러리 메인: `docs/src/sections/ComponentGallery.jsx`

## 2. 코드 작성 가이드라인 (Code Guidelines)
- React 시맨틱 컴포넌트 준수: `@seed-design/react`의 `<Text color="fg.neutralSubtle">` 등 시맨틱 속성을 사용합니다.
- 조종판 컨트롤 라벨: `<code>size</code>:`, `<code>tone</code>:`, `<code>variant</code>:` 와 같이 소문자 백틱 뱃지 코드로 표현합니다.
- 서브 타이틀: 빽틱 없이 `<Text textStyle="t2Medium" color="fg.neutralSubtle">` 형태로 튀지 않는 차분한 미디엄 타이틀을 사용합니다.
- CSS 변수 토큰: 공식 CSS 변수(`var(--seed-color-palette-static-black)`, `var(--seed-color-bg-layer-basement)`)를 정확히 준수합니다.

## 3. UI 스니펫 구조
프로젝트 내 `docs/src/components/ui/` 하위 49개 UI 스니펫 파일은 `@requires @seed-design/react@^2.0.0` 헤더를 포함하며, 직접 수정 가능하도록 제공됩니다.
