# AX Design System Doctor Guidelines

AX Design System 프로젝트 진단 규칙 명세서입니다.

## Rules
1. `outdated-version`: `docs/package.json` 내 `@seed-design/react` 및 `@seed-design/css` 버전이 최신버전과 부합하는지 검사합니다.
2. `no-deprecated-component`: 존재하지 않는 비표준 CSS 토큰(`--seed-color-bg-static-black` 등) 대신 공식 토큰(`var(--seed-color-palette-static-black)`)을 사용하는지 검사합니다.
3. `snippet-generation`: `docs/src/components/ui/` 스니펫의 `@requires` 세대 호환성을 검사합니다.
4. `component-guidelines`: 서브 타이틀 및 레이아웃의 `<Text textStyle="t2Medium" color="fg.neutralSubtle">` 시맨틱 Prop 및 `<code>prop</code>:` 라벨 규격 준수를 검사합니다.
